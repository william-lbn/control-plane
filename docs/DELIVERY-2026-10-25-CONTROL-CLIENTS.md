# 2026-10-25 CLI/MCP 功能验收

CLI 与 stdio MCP 0.1.0 的固定功能基线已完成。共用 OpenAPI 目录、固定入口客户端及当前服务端授权，提供检索、描述、读取和显式批准的写入；采用官方 MCP SDK 2.4.0，验证 2025 初始化及 2026 无状态发现两种模式。见 [配置与限制](CONTROL-CLIENTS.md)和[脱敏回执](acceptance/2026-10-25-control-clients-functional.json)。

Linux 累计 15 组新增功能检查通过，覆盖 293 个操作的唯一目录和游标、固定 origin、凭据和 allowlist、写入双重开关、原键回执、重定向拒绝、取消、私有文件输出、内外网代理、TLS/私有 CA、二进制脱敏、Console CSRF，以及两种协议的官方 SDK 互通。另复验两组受修改影响的路径；空测试文件容器不计作功能用例。未重复 Go、Web、Helm 或其他原功能。

真实服务累计七个检查点通过：专用项目范围读取、CLI 创建并用原键取回同一查询、MCP 读取和版本更新、旧版本及改体同键拒绝、跨项目拒绝、CLI 删除并由 MCP 确认消失、撤销专用 Key 后 CLI/MCP 即时 401。只新建一个保存查询，没有执行 SQL、创建 Compute 或调用商业服务；两个原保存查询的内容摘要保持一致。查询保留删除记录和三代版本，专用 Key 已撤销，凭据与原检查点保留在 Linux。

初次取消测试发现 SDK 取消信号取值错误，修复为官方请求上下文信号后，两种协议均确认原请求被中止且没有第二次请求。初次实机测试把已有保存查询重放的 200 错写为 201；修正测试预期，先核对原资源再以原键续验，没有重新创建。失败记录均保留，没有覆盖为通过。

运行时代码及 lockfile 与实机验证快照逐字节一致；之后只新增一组已在 Linux 通过的 Console CSRF 测试。11 个非文档来源与最终 Linux 检查快照匹配。API/Worker 0.86.0、schema 067、Chart 0.9.83、Core Helm 182 等运行版本保持原验收基线，本增量无需重建和部署原服务镜像。

依赖仅从外网拉取一次，后续质量检查、真实接口和离线打包复用 Linux 缓存。离线运行包包含生产依赖、六个客户端来源、OpenAPI 和许可证，未包含操作员配置或本地二进制；离线安装、解包后的 CLI 检索与官方 SDK MCP 检索通过。包为 2,912,343 字节，SHA-256 `3a261be2c61084df87ac0e699419e357cf0e8abd5b9389ae491390ab415287a5`。原始包在私有交付证据中，不随公开 Git 提交。两个专用终态 QA Job 归档后按 UID/资源版本退休，依赖缓存保留供后续复用。

持续集成新增独立 Linux CLI/MCP gate，并纳入镜像发布前置条件；本记录的功能结论来自本地 Linux 和真实服务，不用尚未结束的托管工作流代替现场证据。当前客户端未提供 SSE/WS 交互、自动分页下载、原生 S3 签名客户端或 5 GiB 文件传输，Windows 运行时与第三方 MCP 宿主未单独认证。

O03 的服务计划和 CLI/MCP 基线现已完成，账单接口及与 I02 关联的支付衔接仍缺。全项目仍有九个业务组和三个其他组未整体闭环；容量和性能后置项见 [当前边界](ENVIRONMENT-DEFERRED-VALIDATION.md)，剩余实现见 [当前状态](FUNCTIONAL-STATUS-2026-10-21.md)。
