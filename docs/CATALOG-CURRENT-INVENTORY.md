# 当前目录身份观察

已验收的功能合同：`GET catalog-identities` 在首次观察历史 `items` 之外，返回只读的 `current_bindings`。它以持久身份代际核对原 OID、名称、Owner 和分支标记，公开身份代际、当前管理代际及创建/变更/重命名/继承来源。当前记录没有历史选项快照，明确返回 `options: not_recorded`；密码与 verifier 不读取，凭据引用和 UID 不公开。

读取不会创建或替换身份记录，不把旧 049 观察静默提升到后来代际。尚未提交的新管理意图显示 `intent_changed`，保持原身份代际。已知同名替换或继承排除不会成为首次观察候选；API 在观察前和提交事务内都拒绝用首次记录覆盖已知 OID/名称。首次观察历史及其独立恢复入口继续保留。

0.69.0 的五项累计现场检查和原目录保全已通过，见 [2026-10-21 当前目录身份展示](DELIVERY-2026-10-21-CATALOG-CURRENT-INVENTORY.md)。旧身份链的受控衔接、默认/系统身份、Backend 名称依赖与外部并发栅栏仍有独立范围。
