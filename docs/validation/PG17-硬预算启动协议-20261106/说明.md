# PG17 内存伸缩的启动与管理接口

出生协议由平台在创建操作时冻结。已有计划缺省使用协议 2，新实例可明确选择协议 3。恢复从原计划读取版本，配置签发、凭据、管理网关与 SQL 路由校验同一 VM/Compute 身份和受支持的协议。版本未知时拒绝启动或路由，绑定的 Secret 还要与创建意图一致。

Linux 118 从 GitHub 核对 autoscaling 原分支对应提交和 Go 模块校验和。在隔离开发镜像中，6 个直接受影响的创建、凭据和 SQL 路由用例通过 Go race；随后实际编译 compute-gateway 和 control-adapter。证据见同目录记录。这里记录的是部署环境已使用的管理接口适配，完整控制面产品验收在三节点 PG17 内存回归之后单独进行。
