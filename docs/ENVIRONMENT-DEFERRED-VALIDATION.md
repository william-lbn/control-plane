# 当前环境验收与后置验证边界

2026-10-25 用户明确：当前三台虚拟机共用 Windows 宿主机的同一块 SSD。已经通过的小对象或基础功能不重复验证；需要更大容量或更高性能的验证，标注后转到更合适的环境。先完成当前环境能验证的业务逻辑并提交代码和证据。

记录必须区分三个状态：**当前环境基础验收已通过**、**代码已完成但目标环境验证后置**、**仍缺实现**。后置一次验证不代表代码已经支持该能力，也不把现有失败记录改为通过。
