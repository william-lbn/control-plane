# 准入固定网关：Mac 基本验收

本批将 Neon 原生准入四路加入中心 TLS 管理网关固定名单：POST /dsg/v1/admission、/admission/status、/admission/close-original、/admission/close-original/status（都带 /dsg/v1 前缀）。不接受任意目标/任意方法/通用 RPC。

准入写也使用观察连接池，避免执行池中的 resize 阻塞关闭门禁；仍逐次验证 current owner/实际 Lease、原 VM UID/config/Service 归属，原 body 和 Bearer 不变。Rust 对完整意图及已验签 epoch 再校验，初始化只读 scope 没有一般控制权限。关闭仅核实 PG 门禁，不产生 VM 许可或预算释放证明。

Go 模块固定到已先推送并核验的自有 Autoscaling 66cff2dd5b7a515fcb01a75b76557a49cd6e8556（功能4490c59d，随后仅用例gofmt）。Neon发行锁相同。主线新0c322d5已独立完整合入95d2002，维护与本业务提交分开。

Mac 两项受影响基本单元/协议测试 -race 通过，0 fail/skip：固定11路保持原始字节/凭据，以及 resize 阻塞时观察/准入四路独立可达；受影响包 vet 和更新Go依赖编译检查通过。测试使用明确协议服务夹具，不冒充实际K8s控制器/Service/证书端到端。日志在工作区 build/dsga-admission-proxy-vet.log、build/dsga-admission-proxy-linux-cli.log（沿用脚本文件名，内容实际为go vet）、build/dsga-admission-cp-dependency。未重复其他功能套件。

复现：`go test -race -count=1 ./internal/control -run '^TestDSGAProxy(ExplicitRoutes|ObservationIndependent)'`。真实 Router→SQL→准确PG 的基本测试由 Neon 新准入模块执行，见 Neon 分支对应中文验收文档。

实际 Agent 持久全预算/启动准入、公开创建worker、完整排空/最终VM等仍属未完成业务接线，继续实施。Linux K8s再验真实RBAC/Service/证书、租约/网络、存储、NeonVM/KVM/HugeTLB/物理回收与性能。当前仅PG17，不构建镜像、不准备部署、不合并main。
